Studio · live demo

Design it. Wear it.

This is a working demo of the creator studio. The garment preview is drawn from the same kind of HTML and CSS a real skin would use, running in a locked sandbox with no scripts and no network. Change the cut, the colors or the code, and watch it update.

Starting points. Every preset is plain HTML and CSS that you can open in the Code tab and change.

Colors
Mode

On a real garment, these are the base settings in the companion app. Brightness also has a hard ceiling for night and driving.

Sandboxed: scripts, network requests and external images are blocked, and only inline CSS and data images run. The real platform adds one more check, rejecting skins that flash more than three times a second, which follows the widely used photosensitive-safety guideline.

About this demo. No AI model runs on this page, and no credits are charged. Simple keyword rules in your browser pick a style, colors and speed, so you can feel the flow. In the real product, the prompt goes to a design model that writes the skin's HTML and CSS, and every result passes the same sandbox and safety checks before you can wear it.

The platform

Three ways to make a skin.

CODE

Write it

HTML, CSS and SVG, with optional GLSL shaders and image sequences for advanced creators. You get a local preview, a garment-shaped canvas, and a command-line tool for people who live in a terminal.

AI

Describe it

Type or say what you want. The designer drafts a skin, you refine it in plain language, and it shows you the code so you can learn from it. Generations cost credits, which you can buy or earn from sales.

REMIX

Build on someone's

Open any skin whose creator allows remixing, change it, and publish your version. Attribution and the creator's share are handled automatically.
